TIKA — PERSONAL LANDING PAGE

Files:
- index.html
- style.css
- script.js
- assets/tika.jpg

Cara pakai:
1. Extract ZIP.
2. Buka index.html di browser untuk preview.
3. Untuk upload ke hosting, upload seluruh isi folder dengan struktur yang sama.

Catatan:
- Website dibuat tanpa framework agar mudah dipasang.
- Font Google Fonts dipanggil dari internet saat halaman dibuka.
- Foto pada assets/tika.jpg adalah foto yang diberikan untuk landing page.
